Features

Everything a memory card needs. Nothing it doesn't.

The same toolset the Android app ships with — card creation, save surgery, deep diagnostics — explained in one place.

Memory Card Management & Creation

  • Create pristine 0xFF unformatted cards, byte-identical to PCSX2 / ARMSX2 output
  • Pre-formatted cards with valid superblock, FAT tables and root directory
  • Capacities from 8 MB up to 16 / 32 / 64 / 128 MB with accurate cluster geometry
  • One-tap in-app formatting, card resize, and ECC ↔ RAW conversion
  • Open PCSX2 folder-type cards (_pcsx2_superblock)

Savegame Management & Tools

  • Import & export .psu, .max, .cbs, .xps and .zip archives
  • Full file listings: sizes, timestamps and copy-protection flags
  • Safe deletion with cluster-chain deallocation and slot re-indexing
  • Toggle copy protection and edit created / modified timestamps
  • Search, region filter and sorting across the whole card

Visuals & Diagnostics

  • 3D save-icon rendering decoded from 16-bit RGB1555 texture data
  • Accurate Shift-JIS / CP932 decoding for JP titles and subtitles
  • icon.sys inspector: lighting vectors, ambient colors, attributes
  • Card diagnostics: superblock version, allocation stats, bad blocks
  • Built-in hex viewer and editor for any file or raw sector

Modern Android UI

  • Material You (Material 3) with dynamic color on Android 12+
  • Retro PlayStation deep-blue theme on Android 8–11
  • Storage Access Framework: internal, SD card and USB-OTG drives
  • Responsive layouts for phones, foldables and landscape
  • Undo / redo editing with explicit save — no silent writes

Formats

Speaks fluent PlayStation.

Every container the scene ever produced for PS2 saves — plus the raw card images emulators actually boot from.

Format Extension Description Support
ECC Memory Card .ps2 Standard 528 B/page image with ECC parity spare area, as used by PCSX2 and ARMSX2. OPEN • EDIT • CREATE
RAW Memory Card .raw.bin.mc2.mcd.vmc Raw 512 B/page images without spare area. Convert to/from ECC on the fly. OPEN • EDIT • CREATE
Folder Memory Card directory PCSX2 folder-style cards holding a _pcsx2_superblock and hierarchical trees. OPEN • EDIT • SAVE
PSU Save Archive .psu Standard EMS / PS2SaveBuilder container. The universal interchange format. IMPORT • EXPORT
Action Replay MAX .max Compressed Datel save containers, unpacked and imported directly. IMPORT • EXPORT
CodeBreaker .cbs Pelican CodeBreaker archives, unpacked and imported directly. IMPORT • EXPORT
SharkPort / X-Port .xps Classic cheat-device upload format from the USB-link era. IMPORT • EXPORT
ZIP Archive .zip Plain compressed backup of a save folder — easy to share anywhere. EXPORT
ECC vs RAW, in one line: ECC pages carry 512 + 16 bytes (data plus Reed-Solomon/Hamming parity) while RAW pages carry 512 bytes flat. SAVESX2 detects either automatically, so you never have to care which one you downloaded.

Guide

From zero to loaded save in four steps.

The 60-second tour of the app. Everything runs on-device — no account, no network, no cloud.

01

Open a card

Tap Open Memory Card and pick a .ps2, .mc2, .raw image — or a PCSX2 folder card — from internal storage, SD or USB-OTG.

02

Create a card

Need a fresh start? Create 8–128 MB cards, unformatted (PCSX2-style 0xFF flash state) or pre-formatted and ready for saves.

03

Import & export

Drop in .psu, .max, .cbs or .xps saves with one tap; export back out as any of those, plus .zip for safekeeping.

04

Maintain

Format, resize, inspect icon.sys, check diagnostics, edit timestamps or hex-edit a file — then hit Save. Undo is always one tap away.

Pro tips from the memory card slot

  • New card for an emulator? Create it unformatted, then format inside the PS2 BIOS or game — maximum compatibility, zero recovery loops.
  • Before risky edits… Export the save as .psu or .zip. Thirty seconds of backup beats thirty hours of replaying.
  • Moving cards between apps? SAVESX2 writes standard images, so cards open straight back up in PCSX2, ARMSX2, AetherSX2 and NetherSX2.

FAQ

Questions? Good. We like those.

Short answers to the things card owners actually ask.

Q1 Is SAVESX2 free? Is it open source?

Yes to both. The app is free, has no ads and no in-app purchases, and the full source is published under the GNU GPL-3.0-or-later. If it saved your 200-hour RPG run, donations via Ko-fi or Saweria are appreciated but never required.

Q2 Which Android versions are supported?

Android 8.0 (API 26) and up. Material You dynamic colors kick in on Android 12+, while older versions get the signature retro PlayStation deep-blue theme.

Q3 Does it work with my emulator's cards?

If the emulator uses standard PS2 card images, yes — PCSX2, ARMSX2, AetherSX2 and NetherSX2 cards (ECC or RAW, 8–128 MB) all open directly, as do PCSX2 folder-type cards. Real-console saves moved over USB-OTG work too.

Q4 What about PS1 saves on the card?

PS1 saves stored on PS2 cards are detected and can be filtered separately from PS2 saves, so mixed cards stay easy to browse.

Q5 The app says my card is "unformatted". Is it broken?

Not at all — that's the clean 0xFF flash-erased state emulators create. You can format it with one tap inside SAVESX2, or format it in the PS2 BIOS / game for maximum emulator compatibility.

Q6 Is editing safe? What if I make a mistake?

Edits live in memory until you explicitly hit Save, and undo / redo plus a cancel-edit option are built in. For belt and suspenders, export important saves as .psu or .zip first.

Q7 Where do I download it, and how do updates work?

Grab the APK from GitHub Releases (see Download below) or build it yourself from source / Actions. The app also checks GitHub releases in-app and tells you when a new version drops.
